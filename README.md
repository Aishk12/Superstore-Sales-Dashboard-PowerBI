# Superstore Sales Analysis Dashboard (Power BI)

## Project Overview
This project analyzes Superstore retail sales data using Microsoft Power BI. The dashboard provides insights into sales performance, profitability, customer segments, product categories, regional performance, and yearly trends.

## Tools Used
- Microsoft Power BI
- Microsoft Excel
- DAX (Data Analysis Expressions)

## Dataset
- Sample Superstore Dataset
- 9,994 Sales Records
- Years Covered: 2016 - 2019

## Key KPIs
| Metric | Value |
|----------|----------|
| Total Sales | 2.30M |
| Total Profit | 286.40K |
| Total Quantity | 38K |

## Dashboard Pages

### 1. Sales & Profit Overview
Features:
- Profit by Category
- Profit by Region
- Profit by Segment
- Profit by Sub-Category
- Year Filter
- Sales and Profit Summary

### 2. DAX Measures Dashboard
Features:
- Average Sales
- Average Profit
- High Sales
- Low Sales
- High Profit
- Low Profit
- Consumer vs Corporate Analysis
- Sales Growth %
- Profit Growth %

### 3. Yearly Trend Analysis
Features:
- Sales Trend by Year
- Profit Trend by Year
- Year-wise Performance Summary

## Key Business Insights
- Technology category generated the highest profit.
- West region recorded the highest profit contribution.
- Consumer segment achieved the highest sales and profit.
- Copiers and Phones were the most profitable sub-categories.
- Tables and Bookcases generated negative profit.
